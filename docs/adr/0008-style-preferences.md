# ADR 0008: Style preferences

Status: research pending. Back burner (post-POC).

## Why
Users want explanation style (e.g. analogies, examples, diagrams) independent of level. Ex: proficient eng still wants analogies in unfamiliar domain.

## Investigate
- Separate dial (`--style a,b`) vs bundled presets
- Style vocabulary: which styles, keep list small
- Interaction w/ budget (analogies cost tokens; bare tier may override)
- Config layering same as other dials
